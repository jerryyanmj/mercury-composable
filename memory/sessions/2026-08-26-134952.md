### Key design decisions recorded

- **MongoDB single-document atomicity**: pipeline update (List<Bson>) for state-change + outbox-append in one `findOneAndUpdate`; no replica set required on hot path.
- **Milestone idempotency**: `{$ifNull: ["$milestones.{name}", {outcome, reason}]}` — first write wins.
- **`_seq` counter**: embedded integer, incremented in pipeline Stage 1, referenced as `$_seq` in Stage 2 outbox payload (field reference resolved by MongoDB).
- **`v1.milestone.record` returns `to_state`**: SETTLED/FAILED/NOOP. Steward-ack-flow maps `result.to_state → model.derived_state`, then passes `model.derived_state → to_state` to `v1.steward.record.status`. Never reads `lifecycle_state` from graph output on the ack path.
- **`graph.executor` in steward-ack-flow**: headers-only (model.instance, text(fulfillment-lifecycle)), NO body mapping.
- **`yaml.cron=classpath:/cron.yaml`** (not `yaml.mini.scheduler`).
- **`web.component.scan=com.accenture`** in all REST-facing apps so `mongo.service` route auto-registers.
- **`order-common-mongodb` artifact ID**: differs from Postgres `order-common` to avoid Maven local-repo collision.
