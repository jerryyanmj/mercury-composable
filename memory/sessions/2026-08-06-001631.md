2. **`conv-vocabulary-precision`** — ADR-0004/ADR-0005 naming rules: Active Knowledge Graph (model) vs
   Knowledge Graph as Application (tagline) vs MiniGraph (engine); one-atom-four-roles vocabulary
   (function/service/task/skill); Human–AI collaboration = cross-cutting, NOT a fourth layer.

3. **`conv-startup-lifecycle`** — Application startup order from `AutoStart.main()`:
   `@BeforeApplication` (0–999) → `@PreLoad` → REST server → `@MainApplication`; CompileFlows at
   sequence 5, CompileGraph at sequence 6; Spring Boot variant via `ApplicationReadyEvent`.

4. **`conv-node-ttl-disambiguation`** — node `ttl` one grammar, three meanings: child-call deadline
   (task/fetcher/extension), script execution deadline (graph.js, 5s default, not model.ttl), store
   record expiry (graph.suspend, mandatory). Model metadata immutability restated.

5. **`conv-graphjs-kernel-threads`** — `graph.js` uses kernel threads, capped at 50 instances; prefer
   `graph.math` or `graph.task`.

6. **`conv-graph-extension-no-star`** — `graph.extension` does not support `*` whole-body target;
   named `input[]` keys only (unlike `graph.task`).

7. **`conv-graph-fetcher-dedup`** — `graph.api.fetcher` deduplicates successful responses within a
   graph instance; failed calls not cached; `{node}.status` always set; 3xx not followed.

8. **`conv-graph-join-semantics`** — `graph.join` completion is success-only; chained joins count only
   when fired; `RESET` re-arms the wait; data race mitigation patterns.
